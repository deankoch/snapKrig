## Overview of Version 0.0.4

This update addresses Errors (and Additional Notes) currently showing in
CRAN Package Check:

`https://cran.r-project.org/web/checks/check_results_snapKrig.html`

These errors are from tests where I randomize arguments. Some invalid choices
were being generated by chance. I have fixed the test scripts so this cannot
happen in future, and I modified two functions to improve error-handling in
the degenerate cases.

Changes:

* modify parameters in "tests/testthat/test-sk-index.R" to avoid randomly generating invalid tests
* update `sk_sub()` to return a `NULL` when result is empty (instead of throwing error)
* update `sk_sub_find()` to return a `NULL` when result is 1x1 (instead of throwing error)
