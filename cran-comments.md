## Overview of Version 0.0.4

This update addresses some errors (and additional note) currently showing in
CRAN Package Check:

`https://cran.r-project.org/web/checks/check_results_snapKrig.html`

These errors come from tests that randomize their arguments. A rare invalid
combination was being generated by chance. I have fixed the test script so this
cannot happen in future.

Changes:

* modify parameters of tests/testthat/test-sk-index.R to avoid randomly generating invalid tests
* update `sk_sub()` to return a `NULL` when result is empty (instead of throwing error)
